# 🐾 AnimalVision AI

### Deep Learning Powered Animal Species Recognition System

AnimalVision AI is an AI-powered wildlife recognition application that identifies animal species from uploaded images using a deep learning model and provides additional animal information through an interactive Streamlit interface.

---

## 🎯 Project Objective

The main objective of AnimalVision AI is to build an intelligent image classification system capable of recognizing different animal species from images.

The system combines:

- 🧠 Deep Learning
- 🖼️ Image Classification
- 🤖 AI-powered Animal Assistant
- 🎨 Interactive Streamlit UI
- 📚 Animal Information System

---

## ✨ Features

### 🐾 Animal Species Recognition

Upload an animal image and the trained deep learning model predicts the animal species.

The application displays:

- Predicted animal
- Prediction confidence
- Animal image
- Prediction status

### 📊 Confidence Score

The application displays the model's prediction confidence using a percentage and progress bar.

### 📖 Animal Information

After prediction, the application provides information such as:

- 🌍 Habitat
- 🍽️ Diet
- 🧬 Scientific name
- ⏳ Lifespan
- 💡 Interesting facts

### 🤖 AI Animal Assistant

Users can ask questions about the predicted animal through the AI assistant.

The application supports:

- 📝 Text-based questions
- 🎤 Voice-based questions
- 🔊 Text-to-speech responses

---
